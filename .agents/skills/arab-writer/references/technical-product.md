# Technical and Product Arabic

## Preserve technical objects

Do not alter:
- commands;
- code;
- API names;
- paths;
- URLs;
- package names;
- model names;
- version numbers;
- schema fields;
- units;
- hardware identifiers;
- standard identifiers.

Keep code blocks LTR and unchanged unless the user asks to modify code.

## Documentation

Prefer:
- action verb;
- prerequisite;
- step;
- expected result;
- error state;
- recovery.

Avoid translating a technical term when the established product terminology is English and translation would reduce precision.

## Product copy

Separate:
- feature;
- behavior;
- limitation;
- requirement;
- benefit.

Do not convert a feature into a guarantee.

## UI strings

Optimize for:
- brevity;
- clarity;
- consistency;
- action orientation.

Do not translate placeholders, variable tokens, or field names unless explicitly required.
