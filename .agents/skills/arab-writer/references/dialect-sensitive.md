# Dialect-Sensitive Editing

Use only when the source is dialectal or the user requests dialect.

## Preserve dialect identity

Do not normalize dialect into MSA unless asked.
Preserve:
- local vocabulary;
- conversational particles;
- natural contractions;
- speaker personality.

## Correct selectively

Fix:
- obvious typing errors;
- accidental repetitions;
- punctuation that blocks readability.

Do not impose formal grammar rules that erase the dialect.

## Cross-dialect adaptation

If asked to adapt to another dialect:
- keep meaning and social intent;
- avoid caricature;
- prefer widely understood regional forms over exaggerated slang;
- preserve names, numbers, links, and technical terms.

If a phrase is culturally ambiguous, prefer neutral Arabic rather than inventing local slang.
