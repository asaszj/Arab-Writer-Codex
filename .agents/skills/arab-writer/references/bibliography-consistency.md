# Bibliography Consistency

When a document contains references, audit consistency without inventing metadata.

Check:
- consistent organization/author naming;
- year/date presence where the source provides it;
- consistent punctuation and ordering within the document's existing convention;
- English/Arabic title handling;
- report, announcement, webpage and presentation labels;
- duplicate references;
- identifiers/URLs only when present in the source.

If the user specifies APA, Chicago, Harvard, etc., apply that style. Otherwise preserve the document's existing style and normalize only obvious inconsistencies.

Do not fabricate a date, URL, DOI, author, issue number or publisher to make an entry look complete.
