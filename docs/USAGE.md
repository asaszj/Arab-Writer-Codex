# Usage Guide

## Proofread only

```text
$arab-writer
دقق النص التالي إملائيًا ونحويًا فقط. لا تغيّر ترتيب الأفكار أو النبرة.
```

## Rewrite naturally

```text
$arab-writer
أعد صياغة النص بالعربية الطبيعية. احذف التكرار والصياغات العامة، ولا تضف معلومات جديدة.
```

## Preserve voice

```text
$arab-writer
حسّن النص مع Voice Lock: حافظ على مستوى المباشرة وطول الجمل والمفردات الخاصة بالكاتب.
```

## Executive

```text
$arab-writer
حرر المذكرة لمجلس الإدارة. ابدأ بالقرار المطلوب ثم الأثر والأرقام والمخاطر والتوصية.
```

## Academic

```text
$arab-writer
حرر أكاديميًا. لا تغيّر المراجع أو أسماء المتغيرات أو النتائج الإحصائية، ولا تحوّل الارتباط إلى سببية.
```

## Financial

```text
$arab-writer
راجع الصياغة المالية. حافظ على المبالغ والنسب والفترات وافصل بين الفعلي والتقديري والافتراضات.
```

## Policy / legal

```text
$arab-writer
حسّن وضوح السياسة مع المحافظة الحرفية على الالتزامات والاستثناءات والمواعيد وأرقام المواد.
```

## Marketing

```text
$arab-writer
اجعل النص التسويقي أقصر وأكثر تحديدًا. لا تستخدم مبالغات أو ادعاءات غير مثبتة.
```

## Bilingual

```text
$arab-writer
راجع النسختين العربية والإنجليزية وتأكد من تطابق الأرقام والقيود والادعاءات والمصطلحات.
```

## Dialect-sensitive

```text
$arab-writer
نظف الرسالة إملائيًا لكن حافظ على اللهجة والنبرة المحكية. لا تحولها إلى فصحى.
```
