# Formatting and RTL

## Preserve structure

Keep:
- headings;
- lists;
- tables;
- blockquotes;
- code fences;
- inline code;
- links;
- footnote markers;
- citation markers.

Do not convert a table into prose unless asked.

## Mixed direction

Keep these LTR:
- URLs;
- emails;
- code;
- file paths;
- API fields;
- identifiers;
- formulas.

Avoid inserting Arabic punctuation inside those tokens.

## Markdown

Use Markdown only when it improves scanability.
Do not create headings for every short paragraph.
Do not overuse bold.

## Tables

Protect each cell's numeric and categorical meaning.
Do not reorder columns unless the user asks or usability clearly requires it.
Preserve totals and subtotals.

## Lists

Use bullets for parallel items.
Use numbering for sequence, priority, procedure, or referenced items.
Do not turn an argument into bullets solely to make it look organized.
